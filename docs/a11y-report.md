# Звіт про доступність

Оцінювання за методикою **WCAG-EM 1.0**. Цільовий рівень — **WCAG 2.1 AA**.

|---|---|
| Дата | 22.11.2026 |

| Підсумок | автоматичні перевірки: **0 порушень**. Ручна перевірка з екранним читачем **ще не виконана** (див. розділ 5) |

## 1. Обсяг і базові технології

HTML, CSS, JavaScript (React), SVG, WAI-ARIA. Перевірено в Chromium (Playwright 1.65.1), ширина 1280 px і 360 px.

Доступність реалізована у власному коді. Оверлеї та сторонні віджети доступності не використовуються.

## 4. Реалізація за принципами WCAG

**Сприйнятність**

- Статус ніколи не передається лише кольором: кожен бейдж — іконка унікальної форми + текст (1.4.1).
- Контраст тексту ≥ 4,5:1, зокрема в бейджах статусів і на темному підвалі (1.4.3); елементи інтерфейсу й фокус ≥ 3:1 (1.4.11).
- Кільце прогресу — `role="img"` з текстовою назвою («Загальний прогрес: 38%»); смуги — `role="progressbar"` зі значенням. Кільцева діаграма — одне зображення з описом, а ті самі дані подано списком поруч (1.1.1).
- Семантична структура: один `h1` на сторінці, послідовні рівні заголовків, `header / nav / main / footer`, списки, таблиці з `caption` і `scope` (1.3.1).
- Адаптивність від 360 px без горизонтальної прокрутки; текст масштабується до 200 % (1.4.4, 1.4.10).
- Мова сторінки в `lang`; посилання перемикача мови має `lang` мови призначення (3.1.1, 3.1.2).

**Керованість**

- Усе доступне з клавіатури; порядок фокуса відповідає візуальному (2.1.1, 2.4.3).
- Посилання «Перейти до вмісту» — перший елемент у порядку табуляції (2.4.1).
- Видимий фокус: контур 3 px із контрастним обрамленням, окремий варіант для темного тла (2.4.7).
- Акордеон за WAI-ARIA APG: кнопка в заголовку, `aria-expanded`, `aria-controls`, панель `role="region"` з `aria-labelledby`; Enter / Space розгортають, ↑ ↓ Home End переміщують фокус між заголовками. Згорнута панель має `hidden` — її вміст недосяжний для табуляції та екранних читачів.
- Мобільне меню: кнопка з `aria-expanded` / `aria-controls`, закривається клавішею Esc.
- Розмір цілей натискання ≥ 44 × 44 px для кнопок, полів і пунктів навігації.
- Анімації короткі (≤ 300 мс для інтерфейсу), лише `opacity` / `transform`; за `prefers-reduced-motion` рух вимикається (2.3.3).

**Зрозумілість**

- Фільтри — стандартні `select` з видимими підписами; зміна фільтра не переміщує фокус і не перезавантажує сторінку (3.2.2).
- Кількість знайдених заходів оголошується через `role="status"` (4.1.3).
- Стан фільтрів зберігається в URL; без JavaScript форма працює звичайним GET із кнопкою «Застосувати».
- Зовнішні посилання мають прихований текст «(відкриється в новій вкладці)».

**Надійність**

- Валідна семантика ARIA (перевірено axe); поточний пункт навігації — `aria-current="page"` (4.1.2).

## 5. Ручні перевірки

| Перевірка | Стан |
|---|---|
| Навігація лише клавіатурою по всіх шаблонах | автоматизовано в Playwright; **ручний прохід не виконано** |
| VoiceOver (macOS, Safari) | **не виконано** |
| Масштаб 200 % і 400 % | **не виконано вручну** (є автотест на 360 px) |
| Режим високої контрастності Windows | **не виконано** (у CSS є правила `forced-colors`) |
| Safari, Firefox | **не виконано** (автотести — лише Chromium) |

Автоматичні інструменти виявляють лише частину проблем доступності. До заяви про відповідність потрібно виконати ручні перевірки з таблиці й дописати результати сюди.

### Сценарій для VoiceOver (15 хвилин)

1. `/` — Tab: перший елемент «Перейти до вмісту»; Enter переводить до основного вмісту.
2. Ротор (VO+U) → заголовки: один `h1`, логічні `h2` / `h3`.
3. Кільце прогресу оголошується як зображення «Загальний прогрес: N%».
4. `/glava-23/sudova-reforma` — фільтр «Статус»: після вибору оголошується «Показано N заходів із M».
5. Акордеон: кнопка оголошує «згорнуто / розгорнуто»; після розгортання вміст читається одразу за кнопкою.
6. Бейдж статусу читається текстом («Прострочено»), іконка не оголошується.
7. Перемикач мови: «English» вимовляється англійською.

## 6. Відомі обмеження

- Адміністративна панель — стандартний інтерфейс Payload; її доступність не оцінювалася. Власний редактор матриці прав — таблиця з підписаними прапорцями.
- Вміст блоку «Embed» (iframe) залежить від стороннього сайту; редактор зобовʼязаний заповнити назву фрейму.
- Альтернативний текст зображень — обовʼязкове поле в колекції `media`; його якість залежить від редактора.
