# Контрольний список безпеки

За OWASP Top 10 (2021). Стан на 22.11.2026, локальний стек. Позначки: ✅ реалізовано і перевірено · ☑️ реалізовано, перевірка — після розгортання · ⬜ не зроблено.

## A01. Порушення контролю доступу

| | Захід | Як перевірено |
|---|---|---|
| ✅ | Єдина access-функція для всіх колекцій; права — з матриці ролі | unit-тести `rbac.test.ts`, e2e `admin.spec.ts` |
| ✅ | Анонімний користувач не може писати; службові колекції (`users`, `roles`, `audit-log`, `sync-runs`) йому недоступні | e2e: 403 |
| ✅ | Чернетки не видно анонімним користувачам | unit-тест; фільтр `_status = published` |
| ✅ | Користувач не може змінити власну роль; без права на `users` бачить лише свій запис | e2e «аналітик» |
| ✅ | Останнього адміністратора не можна видалити чи позбавити ролі | e2e: 400 |
| ✅ | Журнал аудиту незмінний: заборона в застосунку + тригери в БД | e2e: 403 для адміністратора; `UPDATE` / `DELETE` у psql → `audit_log is append-only` |
| ✅ | Захист від CSRF: cookie приймається лише з джерела `SITE_URL`; запити з cookie без `Origin` / `Sec-Fetch-Site` відхиляються | перевірено curl: cookie без заголовків → користувач не розпізнається |
| ✅ | Відкритий API v1 — лише читання, лише опубліковані дані | e2e |

## A05. Неправильна конфігурація

| | Захід | Як перевірено |
|---|---|---|
| ✅ | Заголовки: `Content-Security-Policy`, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Permissions-Policy`; `X-Powered-By` вимкнено | e2e «заголовки безпеки» |
| ✅ | Контейнер застосунку працює від непривілейованого користувача `nextjs`; у робочому образі немає npm / yarn | `Dockerfile` |
| ✅ | PostgreSQL не публікує порти; застосунок слухає лише `127.0.0.1` | `docker-compose.yml` |
| ✅ | GraphQL вимкнено; телеметрію вимкнено; Gravatar вимкнено (адреси користувачів не передаються назовні) | `payload.config.ts` |
| ☑️ | Сервер: вхід лише за SSH-ключем, root і паролі вимкнено, `ufw` — 22, 80, 443, автоматичні оновлення безпеки | [deploy.md](deploy.md), крок 1 |

CSP містить `'unsafe-inline'` для скриптів і стилів — цього потребують Next.js (вбудовані скрипти гідратації) і адмінка Payload. Сторонні джерела скриптів заборонені (`script-src 'self'`). Перехід на nonce — можливе посилення.
